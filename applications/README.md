# applications/

Specifications for the real-world surfaces Cotton Foundation and Taylor's Place live on: which mark, which format, what size, which colorway, which material. Written before the new artwork exists so the design phase produces the right things in the right order.

| Spec | Covers |
|---|---|
| `digital.md` | The new website, the donation flow, email, favicon and avatars, templates |
| `print.md` | Letterhead and stationery, the Taylor's Place sponsorship catalog, donor materials, event print |
| `signage.md` | Taylor's Place gate, entrance, wayfinding, the lodge, vehicles |
| `events.md` | CrawFest and other fundraising events: banners, sponsor walls, tickets, apparel |
| `apparel.md` | Staff, volunteer, and guest apparel; hats; embroidery and print rules |
| `social.md` | Profiles, post and story templates, the avatar, captions |

When artwork for an application is approved, it lives in `assets/` (marks) or a subfolder here named for the application (mockups, production files, vendor specs), with a README.

Every spec assumes the rules in `guidelines/`. Where this folder and a guideline disagree, the guideline wins; fix the spec.
