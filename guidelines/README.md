# guidelines/

How Cotton Foundation looks. Each file is a rulebook for one part of the visual system. `brand/` explains why; these explain how.

| File | Covers |
|---|---|
| `colors.md` | The palette: primary, secondary, accent, neutral; HEX/RGB/CMYK/Pantone; the three golds; colorways; measured contrast |
| `typography.md` | Cormorant Garamond and PT Sans: the four type roles, sizes, tracking, line height, the eyebrow device |
| `logos.md` | The mark and the horizontal lockup: anatomy, measured proportions, files, vector status, clear space, minimum sizes, misuse; the lockup stands alone |
| `sub-brands.md` | How Taylor's Place and CrawFest relate to the Foundation; the existing Taylor's Place mark; the endorsement construction; the descriptor rule for any future program |
| `components.md` | The web parts measured from the old site: header, hero, section opener, buttons, cards, impact band, forms, footer, and what to fix |
| `layout.md` | The 980 px column, section rhythm, radius and shadow, print, presentation, email, social, signage |
| `imagery.md` | Photography direction, the navy overlay, renderings, video, what to avoid |
| `iconography.md` | Utility icons, the two permitted property glyphs, no patterns, charts |
| `brand-usage.md` | Do and do not; sponsors and partners; the reject list; the test |

Machine-readable values live in `tokens/`. Where a value is marked **provisional** or **unverified**, it must be confirmed (with the owner, or with a physical proof) before production; the open items are collected in `brand/decision-log.md`.
