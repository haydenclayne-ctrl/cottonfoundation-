# references/website-screenshots/

Screenshots of the old cottonfoundation.org taken 2026-09-22 in a 1316 × 901 px viewport (JPEG, 1× scale). They exist to show **layout, color, and type**: the transparent header over the hero, the navy overlay, the eyebrow + heading + copy rhythm, the 24 px cards and panels, the button styles, the split hero and split media sections.

**Use only the design.** The copy in these images (headlines, dates, statistics, program names, navigation labels) is the old site's and is superseded; none of it is carried into the new brand (decision log D11). Pages and sections whose content is outside the Foundation and Taylor's Place were not captured.
